# 序章台词稿

## 1. 使用说明

本稿为序章全部对话的逐行台词（写作层），供对话系统（`dialogue-system.md`）录入 JSON。角色 ID 见 `character-visual-guide.md`（wuyang / ali / gatekeeper 守门人 / residue 引渊人残响 / yanpo 砚婆 / xiaozhu 小烛 / narrator 旁白）。语气标注 [像阿砾] 等表示无央 tone 染色。粗体行为关键对白（xumen-prologue-quests 引用）。

## 2. FL-P00：从下面走来的人

**场景：归墟出口 → 石桥。无央苏醒。**

- 旁白：深渊浅层。光从上面漏下来，像一层快要干涸的水。
- 无央（站起，环视）：……（沉默）
- 残响（引渊人，远处灯火）：**往上走。活人总把不要的东西放在上面。**
- 无央：[像自己] 谁在说话？
- 残响：灯在这里。跟着灯走，别回头。
- 无央（调查石灯后）：这盏灯……是朝下的。（残响第二句）——「灯不能朝下。朝下的灯，照的是回不来的路。」
- 旁白：地面开始崩裂。教学提示：闪避。
- 无央（抵达墟门外）：城。有人在往下面推东西。
- 守门人（城门上）：**退回去。墟门只接死人，不放死人回来。**
- 无央：[像阿砾] 我不是死人。（迟疑）……大概不是。

## 3. FL-P01：墟门只接死人

**场景：墟门外 → 停尸棚。**

- 守门人：没有命契？来人——有衡吏在城里，正好拿你问话。
- 阿砾（上前）：慢着。她是下面上来的？……归墟今天吐了一批。按规矩，归墟吐出来的东西，先归送葬人验。
- 守门人：验什么？
- 阿砾：验它是不是人。跟我来。
- 阿砾（停尸棚内，检查石脉尸体）：墟门只接死人。你从下面走上来，算哪一种？
- 无央：**我不知道。**
- 阿砾：**那就先活着，名字以后再找。**
- 无央（触碰尸体，听到回声）：……它在说话。不是尸体在说——是送葬道那头的什么。
- 阿砾（沉默片刻）：送葬队，三天前出去，到现在没回来。帮我查他们，我给你一张临时命契。够你走到下一个城。
- 无央：[像阿砾] 你帮每个来历不明的人都这么费心？
- 阿砾：不。我只帮还没死透的。

## 4. FL-P02：送不走的亡者

**场景：送葬道。**

- 阿砾：车翻了。棺木没散，人散了。
- 无央（调查送葬车）：教学提示：攻击。第一个腐化者起身。
- 无央（击败第一名腐化者后）：他穿的是送葬队的衣服。
- 阿砾：是。送葬队的人，现在成了送葬的对象。
- 无央（面对火蚀腐化者）：教学提示：水架势——它的石脉在发红。
- 阿砾（远处）：红的是火性石脉。土架势挡不住，水克火。你想活，就换架势。
- 无央（调查棺木，空棺）：里面没有尸体。
- 阿砾（翻出刻着编号的废弃物）：这些是……五衡院的记号。他们往归墟里送的，不只是死人。
- 无央：[像阿砾] 那是什么？
- 阿砾：我不知道。但我打算查清楚。

## 5. FL-P03：墓门无名

**场景：封印庭院。**

- 阿砾（查看墓门）：墓门要命契。可我手里这张，门上的名字全被凿了——谁凿的？
- 无央（调查封印桩）：教学提示：互动。石脉亮着。三根桩，一个顺序。
- 无央（稳定第一根桩后，闪回）：……我看见一个人，被推进归墟。他喊的不是救命，是「我名字还在宗谱上」。
- 阿砾（第二根桩）：这是墓契宗族的笔法。他们把自己的先人，也凿掉了。
- 无央（第三根桩）：我看见……（停顿）我不记得他的脸了。只记得他被推下去时，手里攥着一截绳子。
- 阿砾（推墓门，门不动）：门不认我。
- 无央（伸手，墓门亮起）：……它认我。（承受裂片，身体出现黄绿色裂纹）
- 阿砾：你……（停顿）墟门开了。这事，先别让城里人知道。

## 6. FL-P04：负碑之物

**场景：负碑兽巢穴。**

- 阿砾：这是碑兽。碑兽峡的东西，不该在这里。
- 无央：它背上那块碑……上面全是名字。
- 阿砾：被凿掉的名字。都堆在它身上。
- 无央（战斗开始）：它不让我们过去。
- 阿砾：那就让它过去。……打死它，让碑落地。

**（首领战结束，处决执念闪现 + 净化/吸收二选一）**

- 执念画面：一名衡吏把一卷墓契丢进归墟；碑兽幼崽在啃食被丢弃的名字。
- 无央（净化后）：它想记住那些名字。
- 阿砾（低声）：那就记住吧。碑倒了，名字还在。（无央获得土之本源裂片）
- 无央（触摸裂片）：……后面有光。裂井开了。

## 7. FL-P05：第一段残响

**场景：归墟裂井（记忆演出，不可战斗）。**

- 旁白：画面褪色。只有五衡院封印上的颜色保留。
- 残响（衡吏投掷声）：疾病。失败的实验。被删掉的名字。丢下去。
- 残响（引渊人）：他们在封深渊？不——**他们不是在封住深渊。他们在往里面倒东西。**
- 无央：[像自己] 那……我是什么？我也是被倒下去的？
- 残响（停顿）：你不一样。你是被缝起来的。
- 无央：缝起来做什么？
- 残响：为了把倒下去的东西，一件一件取回来。（停顿）继续走。其余碎片，还在五境里。
- 无央：……上一代也像你这样说话吗？
- 残响（沉默，灯暗）：回去吧。她在等你。
- 阿砾（墟门，迎上）：回来了。身上那股味儿，像是从账本里爬出来的。（停顿）听着——要是这是真的，墟门守的就不是天下，是一桩旧账。
- 无央：旧账……要翻吗？
- 阿砾：翻。但得换个地方翻。走吧，我带你出城。

## 8. FL-S01：一块空墓位

**场景：墟门墓园。**

- 砚婆：空墓位。命契上划掉了名字——被宗族除名的送葬人，连坟都不能有。
- 无央（调查旧墓契）：他的名字……不是自愿划掉的。
- 砚婆：自愿？这世上哪有自愿没名字的人。（叹气）你要么把他写回原宗族，要么，给他立个「无名者」的位子。你选。
- 无央（写回宗族）：他该回他自己的姓。
- 无央（共同墓位）：名字没了，人还在。位子给他，也给以后所有没名字的。
- 砚婆：……行。落葬吧。这活儿，我干了四十年，头一回觉得埋的不是土。

## 9. FL-S02：灯不能朝下

**场景：送葬道侧路 → 归墟出口石灯区。**

- 小烛：灯……送葬队把石灯落在下面了。灯不能朝下，朝下就照不见回来的路了。可我不敢下去。
- 无央（找回石灯，灯芯是异类记忆）：灯芯……是记忆。它不想灭。
- 小烛：你要把灯灭了？
- 无央（熄灭）：记忆留着，灯就永远朝下。让它熄吧。
- 无央（保留，转向）：灯可以朝上。记忆留着，照着前面。
- 小烛（接过灯，鞠躬）：谢谢。……它还在亮。真好。
