# 教学系统规格

## 1. 定位

定义序章 10 个教学点的覆盖表、教学提示 UI 形式与已看状态机制。原则：每个教学点有主教学场景 + 至少一次低压力复现；已观看的教学提示不重复强制暂停（xumen-prologue-quests 第 7 节验收项）。

## 3. 教学提示 UI

- 形式：屏幕中央下方文字条 + 按键图示（如「SPACE 闪避」），首次出现时游戏暂停 2 秒自动继续，不阻塞操作。
- 位置：不遮挡战斗 HUD 与敌人稳定条（ui-spec 布局约束）。
- 内容：一句话说明 + 按键提示，不出现术语堆砌（「相克破稳」首次出现时显示「水克火：击中它的红色石脉」）。
- 关闭：设置菜单可关闭教学提示（无障碍项，ui-spec 第 6 节）。

## 4. 已看状态机制

- 每个教学点一个全局标志：`tutorial_seen_<id>`（id 为教学点编号 01–10）。
- 标志写入存档（save-system 存档内容 `tutorial_seen`），读档后已看的不再强制暂停。
- 复现场景中的提示以非暂停形式出现（角落小字），不打断战斗。
- 设置菜单提供「重看教学」入口（重新播放全部提示，不改存档标志）。

## 5. 与验收项的关系

xumen-prologue-quests 第 7 节验收项逐条对应：

| 验收项 | 对应机制 |
|---|---|
| 主线不做支线可连续完成 | 教学不依赖支线 |
| 任务目标始终单一主目标 | HUD 规范（ui-spec） |
| 已观看的教学提示不重复强制暂停 | 本规格第 4 节 |
| 土、水架势各至少一次必须理解的场景 | 覆盖表 #8/#9 |
| 负碑兽攻击不依赖颜色即可辨认 | 三重提示（monster-bestiary） |

## 6. 验收标准

- [ ] 覆盖表 10 项全部实现，每项有主教学 + 复现。
- [ ] 教学提示首次出现暂停 2 秒，复现时非暂停。
- [ ] 已看标志随存档持久化，读档不重复。
- [ ] 设置菜单可关闭教学与重看教学。
- [ ] 教学提示不遮挡战斗 HUD 与稳定条。
