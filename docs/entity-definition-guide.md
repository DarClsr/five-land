# 实体定义规范：地图、人物与怪物

## 1. 目的

统一「怎么定义」一套实体：每个地图区域、每个出场人物、每种怪物都按固定字段模板填写，避免设定散落在不同文档里口径不一。本文档提供三套模板、现状整理与优先填充顺序。

模板字段分两类：

- **设定字段**：写入对应的世界观文档（`docs/world-map-and-art.md`、`docs/characters-and-quests.md`）。
- **生产字段**：写入素材合同（`docs/art/character-asset-contract.md`），决定生成素材的输入。

## 2. 地图风格定义模板

每个区域按以下字段定义，其中「现状」列标注已在 `world-map-and-art.md` 中定义的内容：

| 字段 | 说明 | 现状 |
|---|---|---|
| 区域名 | 中文名 + 内部代号 | 已定义 |
| 地理与构成 | 主要城镇/聚落/野外/遗迹/首领区节点清单 | 已定义 |
| 主材质与对比色 | 地面/建筑主材质 + 高识别对比色 | 已定义 |
| 光照与天气 | 光向、天气类型、昼夜特征 | 已定义 |
| 标志性效果 | 每境独有的动态效果（落叶、灰烬、石化蔓延等） | 已定义 |
| 方向标志 | 每个区域至少一个可辨认的地标（视觉规范要求） | 待补 |
| 声音环境 | 环境音基调：风声、虫鸣、金属敲击、水声节奏 | 待补 |
| 生活习俗 | 2–3 条核心习俗 + 1 条禁忌 | 已定义 |
| 腐败表现 | 该境拒绝的相克 + 腐败的症状 | 已定义 |
| 恢复后变化 | 循环恢复后场景/居民变化 | 已定义 |
| 战斗特效配色 | 该境元素的伤害/技能配色与纹样（见 `world-map-and-art.md` 第 9 节） | 已定义 |

**待补字段的填写规范**：

## 3. 人物定义模板

所有出场人物（主角、核心角色、支线角色、NPC）按以下字段定义：

| 字段 | 说明 | 必备程度 |
|---|---|---|
| 姓名与身份 | 名字 + 职业/境属 | 必备 |
| 登场 | 在哪一幕、什么情境下第一次出现 | 必备 |
| 性格 | 3 个关键词 | 必备 |
| 个人矛盾 | 该角色代表本境拒绝承担的一种代价 | 必备（主角色） |
| 与无央的关系 | 情感/功能关系，一句话 | 必备 |
| 视觉锚点 | 一眼可认的身份物件（阿砾的墓契木牌、青檀的药匣） | 必备 |
| 剪影关键词 | 5 个以内，供素材生成使用 | 生产必备 |
| 配色 | 主色 + 对比色，符合该境地域效果表 | 生产必备 |
| 动作特征 | 待机/移动/常用动作的个性（克制、跳跃、拖步） | 生产必备 |
| 语气 | 说话节奏与常用句式 | 台词写作必备 |
| 剧情功能 | 任务、终章作用、结局计分点 | 必备（主角色） |
| 素材优先级 | 序章 / 第一幕 / 后续 | 生产必备 |

### 3.1 已定义人物盘点

| 人物 | 文字设定 | 视觉定义 | 素材优先级 |
|---|---|---|---|
| 无央 | 完整（角色文档 + 装备文档） | 完整（素材合同 + 造型参考图） | 已产出待机/行走/攻击起手 |
| 阿砾 | 完整 | 完整（素材合同） | 序章 |
| 太衡 | 完整 | 待定义 | 第二幕前 |
| 引渊人 | 完整 | 待定义 | 序章（残响形式）/ 终章（实体） |
| 青檀 | 完整 | 待定义 | 第一幕 |
| 白刃 | 完整 | 待定义 | 第一幕 |
| 离照 | 完整 | 待定义 | 第二幕 |
| 沈汐 | 完整 | 待定义 | 第三幕 |
| 砚婆、小烛（序章支线） | 一句话设定 | 待定义 | 序章 |
| 苔七、槐娘、烬童、炉婆、石禾、缄伯、铃九、余锋、泊生、镜姑 | 完整（支线条目） | 待定义 | 各境支线制作时 |

### 3.2 支线人物定义要求

支线人物按同一模板填写，但只要求「视觉锚点 + 剪影关键词 + 配色」三项生产字段，不做完整动作清单（支线人物多为对话场景，复用主人物动画骨架）。示例：

- 砚婆：视觉锚点=半旧守墓斗笠与一把从不离身的铁锹；剪影=佝偻、宽斗笠、垂手；配色=土境黄褐 + 旧纸白。
- 缄伯：视觉锚点=半石化的左手与刻痕；剪影=宽肩、半身灰白、缓慢；配色=土境黄褐 + 石脉青灰。

## 4. 怪物定义模板

每种怪物按以下字段定义，覆盖战斗与生产的全部需求：

| 字段 | 说明 |
|---|---|
| 名称与类型 | 名称 + 普通 / 精英 / 首领 |
| 出身 | 原为谁 / 由什么腐败而成（世界观一致性来源） |
| 外观特征 | 不对称点、识别侧、可读的攻击侧 |
| 五行属性 | 元素、稳定值（见 `docs/combat-system-spec.md` 数值表） |
| 招式表 | 每招含动作 / 地面形状 / 声音三重提示 |
| 执念闪现 | 处决时的执念画面（见 `docs/combat-narrative-fusion.md` 第 2 节） |
| 破稳与处决 | 相克破稳要点、处决窗口表现 |
| 动作清单 | 待机/移动/攻击/受击/死亡，是否循环 |
| 素材优先级 | 所属制作阶段 |

### 4.1 已定义怪物盘点

| 怪物 | 文字设定 | 视觉定义 | 缺口 |
|---|---|---|---|
| 普通腐化者（土行） | 送葬队员出身、外观、动作表已定义 | 已定义 | 无（可生产） |
| 火蚀腐化者 | 仅在 FL-P02 战斗配置中提过（释放火性石脉） | 无 | 需补全模板 |
| 负碑兽（首领） | 三阶段招式已定义（冲撞/火链/碑山压顶） | 无 | 需补外观、出身、执念闪现 |

### 4.2 示例：火蚀腐化者（按模板补全）

- 名称与类型：火蚀腐化者，普通。
- 出身：原为墟门送葬队员，与土行腐化者同队；在送葬道被火性石脉（五衡院倾倒的失控元素）侵蚀。
- 外观特征：与普通腐化者同体型，右侧身体覆盖熔红石脉与暗色火纹；攻击侧为右臂，挥击带余烬拖尾。
- 五行属性：火；稳定值 100。
- 招式表：
  1. 火脉挥击：右臂后拉 → 向前横扫（动作：明显后拉；地面：扇形灼痕；声音：余烬爆裂声）。
  2. 石脉喷发：原地蹲伏 → 身周爆出火性石屑（地面：扩散圈；声音：低沉喷发声）。
- 执念闪现：他正在把一封家书塞进棺木——他至死都在执行「把东西送下去」。
- 破稳与处决：水架势相克破稳；处决演出为火焰熄灭、石脉褪色。
- 动作清单：待机（右臂火纹明灭）/移动（拖步，余烬脱落）/攻击/受击/死亡（火纹熄灭后石化），与普通腐化者共享骨架。
- 素材优先级：P2 序章。

### 4.3 示例：负碑兽（视觉与出身补全）

- 名称与类型：负碑兽，首领。
- 出身：驮负无名石碑的异兽（土境「碑兽峡」迁徙兽类），被五衡院倾倒的废弃物压垮，碑面刻满被凿去的名字；它背负的不是碑，是土境不肯承认的历史。
- 外观特征：四足石兽，背驮巨大无名石碑，碑与背甲融合；锁链从碑沿垂下，攻击时锁链发红；口鼻处有裂隙火光。
- 五行属性：土；稳定值 150（首领）。
- 招式表（沿用《墟门序章任务规划》FL-P04）：
  1. 负碑冲撞：追踪后直线冲撞（地面：犁出沟痕；声音：巨石滚动）。
  2. 火链砸地：背部锁链发红后砸向扇形区域（动作：锁链上举；地面：扇形裂纹；声音：铁链脆响 + 落点闷响）。
  3. 碑山压顶：生命低于一半后跃起落地（动作：明显下蹲蓄力；地面：整场地震波 + 中心高亮；声音：轰鸣）。
- 执念闪现（最终终结时）：一名衡吏把一卷墓契丢进归墟，转身看见碑兽幼崽在啃食被丢弃的名字——碑兽想记住它们。
- 破稳与处决：水架势快速破火链阶段稳定；土架势可防震波（沿用 FL-P04 设计）。
- 动作清单：待机（石碑起伏呼吸）/移动（四足沉重步）/三招式/受击/死亡（石碑倾倒、名字显形后崩解）。
- 素材优先级：P2 首领战。

## 5. 五境怪物生态规划（方向）

后续每境至少两类普通怪物 + 一类精英 + 一名首领，全部按「出身 = 该境拒绝相克的受害者」原则设计：

| 境 | 普通怪物方向 | 精英 | 首领 |
|---|---|---|---|
| 木境 | 寄生花缠绕的活物、拒绝凋零的分蘖树人 | 母树祭司的缝合体 | 母树（本体战，仪式结构见任务差异化设计） |
| 金境 | 失去情感的「活器」工人、磁砂矿谷的牵引铁偶 | 天衡官的无感卫队 | 天衡钟（机关型首领） |
| 火境 | 余烬重演的焚影、热浪中的人形灰烬 | 巡火队被腐化的队长 | 不熄炉核心 |
| 水境 | 记忆渗透的水影、失名水道中的溺影 | 观忆院记忆卫兵 | 沉镜宫守忆者 |
| 土境 | 封存于塑像中的「祖先」、碑兽峡石兽 | 墓契宗族执法者 | 镇岳台封印守卫 |

怪物出身一律写清「他曾经是谁 / 它曾经是什么」，与处决执念闪现系统直接挂钩。

## 6. 优先填充顺序

1. **P2 序章**：火蚀腐化者（补全）、负碑兽外观与出身（补全）、砚婆与小烛视觉三要素。
2. **P3 素材阶段**：按素材合同生成火蚀腐化者与负碑兽素材。
3. **第一幕**：青檀、白刃视觉定义 + 木境、金境普通怪物各两种（填模板后进素材合同）。
4. **第二幕起**：太衡、离照、沈汐及后续怪物按模板填充，随各境制作推进。

- [ ] 每种怪物在素材生成前完成模板全部字段，含出身与执念闪现。
- [ ] 五境怪物生态表在第二幕制作前完成全部首领与精英设计。
