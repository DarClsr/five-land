# 五行战斗系统总规格

## 1. 目的与范围

本文档统一「五行稳定」「元素资源」「处决窗口」「架势切换」四套概念的长期规格，解决以下三个已有缺口：

- 相生规则落地为伤害 ×0.8，与「相生用于连招与强化」的设计意图相矛盾，玩家无法理解“生”为何是减益。
- 「五行稳定」是相克破防与处决教学链的承重墙，但没有任何数值与显示规格。
- 架势切换的 Q 键循环只在两架势时可行，全量开放五架势后会成为操作瓶颈。

服务范围：序章灰盒（土、水两架势）验证 → 全量五境。序章期间只实现规格中的土、水部分，其余为长期约束。

## 2. 设计原则

- 相生是铺垫，相克是结算：相生攻击积攒资源，相克攻击削减稳定并开启处决。
- 每个概念必须有主教学场景和一次低压力复现（如封印桩复用破稳）。
- 敌人状态（稳定值、失衡）必须同时有颜色、形状与音效提示，不依赖单一通道。
- 资源与状态属于战斗系统，不写进 UI 或场景节点；UI 只读取信号。

## 3. 核心概念

### 3.1 五行稳定

敌人的“元素平衡”数值，代表其承受相克冲击的能力。

- 默认稳定值 100，首领 150。
- 相克攻击每次命中削减 25；相生攻击不削减。
- 稳定归零时敌人进入失衡（见 3.3）。
- 未受击时每秒恢复 5；被击中后 3 秒内不恢复。
- 显示：敌人头顶细条，按 100%–50%–0% 分为绿、黄、红三段；失衡时闪白并出现破甲纹样。

### 3.2 元素资源

每套架势拥有独立的资源池，是相生攻击的产出与架势技能的消耗。

| 架势 | 资源名 | 序章状态 |
|---|---|---|
| 土 | 镇力 | 实现 |
| 水 | 流转 | 实现 |
| 木 | 生机 | 后续 |
| 火 | 薪火 | 后续 |
| 金 | 契力 | 后续 |

- 上限 100，不随时间衰减。
- 获取：相生攻击命中 +30；精准闪避 +15；敌人失衡时任意攻击 +50。
- 消耗：架势技能与处决技（见 3.4、3.5）。
- 相生语义落地：以水生木为例，水架势攻击木系敌人造成 0.8 倍伤害，但木资源 +30。“生”不再是无解释的减益，而是明确的资源输送。
- 切换架势不清空资源，鼓励战斗中混搭。

### 3.3 失衡与处决窗口

- 稳定归零后敌人进入失衡 2.5 秒，期间受击伤害 ×2.0，无法行动。
- 失衡期间使用处决技（消耗 50 对应资源）可处决普通敌人；首领只受 ×4.0 终结伤害，不秒杀。
- 失衡结束后的 10 秒内敌人获得元素免疫，无法再次破稳。
- 表现：失衡时敌人硬直、身体出现对应元素的裂纹光效，地面出现短暂提示圈。

### 3.4 架势技能（资源消耗出口）

每架势一个基础技能，序章先落地土、水：

| 架势 | 技能 | 消耗 | 效果 |
|---|---|---|---|
| 土 | 镇岳 | 50 镇力 | 格挡震波，削减附近敌人稳定 30 |
| 水 | 回潮 | 50 流转 | 短距位移，留下水影减速敌人 |
| 木 | 裁枝 | 50 生机 | 牵引标记目标，回复少量生命 |
| 火 | 燎原 | 50 薪火 | 中距离突进枪刺，附加灼烧 |
| 金 | 断契 | 50 契力 | 背袭强化，下一次攻击额外破稳 25 |

装备套装共鸣提供被动，不新增资源类型。

### 3.5 处决技

- 失衡窗口内、消耗 50 对应资源触发的终结动作。
- 普通腐化者：直接处决（演出约 1 秒，不拖慢战斗节奏）。
- 首领与精英：造成 ×4.0 终结伤害并清空其失衡状态。
- 输入：失衡期间按攻击键自动判定，无需单独按键，避免教学负担。

## 4. 架势切换长期方案

- 当前：Q 键循环切换（两架势可用）。
- 目标：Q 循环 + 数字键 1–5 直选；手柄 LB/RB 循环 + 长按打开轮盘。
- 切换冷却 0.3 秒；切换不清空资源。
- 序章阶段即预留数字键映射，验证直选与循环并存的手感，不等五境完成再返工。

## 5. 架势与装备的关系

两轴独立，需要在序章通过一次 UI 或对话明确表达：

| 轴 | 内容 | 获得方式 |
|---|---|---|
| 架势 | 能力来源：五行技能与资源 | 主线教学与剧情解锁（序章 FL-P02 解锁水架势） |
| 装备 | 流派强化：数值、动作组、套装共鸣 | 各境任务节点（水行装备在水境主线） |

- 玩家可持有已解锁架势但未获得对应装备，UI 需同时显示「架势已解锁」与「装备未获得」两个状态，避免“穿上水行衣才能用水架势”的误解。
- 序章土、水架势与「归墟素衣、归墟双匕」初始装备并存，作为两轴独立的第一个演示场景。

## 6. 数值表（灰盒期草案）

| 参数 | 普通敌人 | 首领 | 备注 |
|---|---|---|---|
| 五行稳定 | 100 | 150 | 首领失衡窗口缩短至 2 秒 |
| 相克破稳 | 25/命中 | 20/命中 | 首领需要更多相克攻击 |
| 失衡窗口 | 2.5 秒 | 2.0 秒 | 首领不可处决 |
| 失衡后免疫 | 10 秒 | 10 秒 | 防止无限破稳循环 |
| 相生伤害倍率 | 0.8 | 0.8 | 必须伴随资源奖励 |
| 相克伤害倍率 | 1.5 | 1.5 | 维持现有 five_element_rules.gd |
| 处决伤害 | 秒杀 | ×4.0 | 消耗 50 资源 |
| 资源获取 | 相生 +30、精准闪避 +15、失衡命中 +50 | 同左 | 上限 100 |

所有数值为灰盒期草案，P4 特效与手感调优后回填。

## 7. 与现有实现的关系

- `scripts/combat/five_element_rules.gd`：保留 `damage_multiplier`，新增 `stability_damage(attacker, defender)` 与 `resource_gain(attacker, defender)` 静态查询。
- `ElementComponent`：增加资源池与稳定值状态，发出 `resource_changed`、`stability_changed` 信号。
- `HitboxComponent`：命中结算区分相克破稳与相生资源输送。
- 实现时遵循项目组件化模式与信号解耦，并按仓库约定先调用 `godot-prompter:*` 相关技能。

## 8. 开放问题

- 相生 0.8 倍率是否长期保留：保留，但必须伴随资源奖励；若手感验证中资源正反馈不足，则改为 1.0 倍 + 更强资源产出。
- 破稳是否受架势等级或装备词条影响：当前不设计等级成长，待第二境数值表出现后再评估。
- 吸收腐败对资源与稳定的影响：留待腐败系统单独规格，不在本文档扩展。
