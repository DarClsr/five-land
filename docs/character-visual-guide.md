# 人物视觉定义

## 1. 说明

按《实体定义规范》的人物模板填充全部出场人物的视觉字段。核心角色填完整字段，支线角色填「视觉锚点 + 剪影关键词 + 配色」三要素加一句语气。本文档是素材生成（`game-assets` / Meowa CLI）的直接输入，与 `docs/art/character-asset-contract.md` 的共通规范配合使用。

共通约束（沿用素材合同）：固定白发、青色瞳孔、脸型与 Q 版身高为无央身份锚点；其余角色各自锁定视觉锚点；全部角色保持左上方冷色月光光向与旧版画/纸扎/墓契的志怪质感。

## 2. 核心角色

### 无央（已有完整定义，见素材合同与装备文档）

- 视觉锚点：长白发、青色瞳孔、归墟双匕。
- 本表不重复，仅记录扩展：腐败纹路 0–3 级外观变化见《战斗与叙事融合规格》第 5 节。

### 阿砾（已有完整定义，见素材合同）

- 视觉锚点：腰间墓契木牌、绳结、折叠白布；深棕短发、风尘感。
- 本表不重复，仅记录语气：务实、克制，习惯用墓契确认每个人的位置。

### 太衡

- 性格：庄重、计算、疲惫的慈悲。
- 视觉锚点：五衡院衡印（一方黑色印玺，从不离手）；玄黑与旧金官袍，领口绣褪色的五行环。
- 剪影关键词：高冠、宽袍、端正、衡印。
- 配色：玄黑 + 旧金 + 一点褪色的五行色（五色各一处，均已发灰）。
- 动作特征：极少移动，说话时站定；唯一习惯动作是摩挲衡印。
- 语气：平稳、慢、每句话都像在核算成本。
- 素材优先级：第二幕（不熄炉场景）前定稿；终章决战复用。

### 引渊人

- 性格：温和、引导性、回避。
- 视觉锚点：一盏青白纸灯（永不熄灭的残响灯火）；形体半透明，兜帽斗篷。
- 剪影关键词：提灯、斗篷、无脚（衣摆下是雾气）、渐似无央。
- 配色：青白灯火 + 近黑斗篷 + 透明雾气。
- 动作特征：飘行，落地无声；把灯递向无央是标志动作。
- 语气：温和、引导性，被问及「上一位容器」时停顿。
- 素材优先级：序章只需残响形式（灯光 + 声音），实体形象在第三幕水境揭示后定稿——形体必须与无央同源渐似（见《叙事差异化与写作原则》第 4 节）。

### 青檀

- 性格：温和、精确、固执的救赎执念。
- 视觉锚点：随身药匣（打开时露出寄生花枝）；发间一枚孢子簪。
- 剪影关键词：长发束起、药匣、窄袖、微微前倾。
- 配色：木境深绿 + 灰白树皮 + 紫红菌菇点缀。
- 动作特征：习惯指尖点脉；说话时手指会无意识地在药匣上敲节奏。
- 语气：温和精确，对「救活所有人」近乎固执。
- 素材优先级：第一幕（木境）。

### 离照

- 性格：直接、守诺、克制的情感。
- 视觉锚点：腰间巡火灯（一束不灭的小火，火境家人的余烬记忆）；肩甲上的旧灼痕。
- 剪影关键词：披甲、长枪、火灯、立姿挺拔。
- 配色：朱红 + 黑玄武岩 + 青色祭火。
- 动作特征：立正、前倾，行军步；点灯是习惯动作。
- 语气：直接、短句、守诺。
- 素材优先级：第二幕（火境）。

### 白刃

- 性格：敏锐、讽刺、面对情感时笨拙。
- 视觉锚点：腰间衡刃（他的情感被铸成的武器，刃身有断纹）；右手缠工布。
- 剪影关键词：瘦削、半破披风、衡刃、垂肩。
- 配色：银灰 + 锈红 + 墨黑（金境主色，锈红为他私藏的一线暖色）。
- 动作特征：说话时习惯摸刃；讽刺时眉梢上挑，被说中心事时低头。
- 语气：敏锐、讽刺，笨拙时突然变短句。
- 素材优先级：第一幕（金境）。

### 沈汐

- 性格：善解人意、无法稳定使用「我」。
- 视觉锚点：水镜碎片挂坠（垂在胸前，会映出别人的脸）；湿发、赤足系铃。
- 剪影关键词：垂发、水镜、赤足、缓步。
- 配色：水境深青 + 琥珀舟灯 + 白色雨幕。
- 动作特征：动作缓慢，经常停顿；习惯触摸空气（像在触碰记忆）。
- 语气：柔和、停顿，说到自己时会改用第三人称。
- 素材优先级：第三幕（水境）。

## 5. 验收标准

- [ ] 每位角色素材生成前完成全部字段（核心角色）或三要素（支线角色）。
- [ ] 视觉锚点与角色个人矛盾绑定（阿砾=墓契、白刃=衡刃、缄伯=石化），不出现「换个发型就是另一个人」的定义。
- [ ] 支线角色三要素与其境属配色一致，可被玩家一眼归类到所属境。
- [ ] 引渊人实体形象与无央同源渐似，不与任何常规「引导者」形象重复。
