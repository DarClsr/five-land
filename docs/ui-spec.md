# UI/HUD 规格

## 1. 设计原则

- 风格：国风纸墨基调——界面以旧纸、墨线、墓契与封印纹样为主，不使用玻璃拟态或科幻面板。
- 基准：1280×720，`canvas_items` 拉伸模式（project.godot 已配置）。
- 可读性优先：战斗状态（稳定条、资源、架势）必须同时具备颜色与形状提示，色觉差异玩家可识别。
- 无障碍：减少闪光、屏幕震动、粒子密度三项开关（TODO P4 已有规划），UI 必须全部遵循。
- 单一数据源：UI 只读信号与资源数据，不直接操作战斗逻辑（combat-system-spec 第 2 节约束）。

## 2. 战斗 HUD

| 元素 | 位置 | 内容 | 状态 |
|---|---|---|---|
| 生命条 | 左下 | 当前/上限 + 裂纹装饰 | 常驻；受伤时闪动 |
| 元素资源 | 左下（生命条上方） | 当前架势资源（镇力/流转）细条 | 常驻；相生命中时增长动画 |
| 架势指示 | 左下（资源条旁） | 当前架势图标与名称 | 常驻；切换时 0.3 秒过渡 |
| 相生循环环 | 左下（架势旁） | 五行环，循环进度亮起 | 仅相生循环连段进行中显示（combat-narrative-fusion 4.2） |
| 敌人稳定条 | 敌人头顶 | 绿→黄→红三段细条 | 战斗中出现；失衡时闪白 + 破甲纹样（combat-system-spec 3.1） |
| 处决提示 | 敌人头顶 | 失衡窗口倒计时 + 处决键提示 | 失衡期间显示 |
| 执念闪现 | 全屏 | 1 秒执念画面 + 净化/吸收二选一按钮提示 | 处决触发时（combat-narrative-fusion 2.2） |
| 污染选项标记 | 对话选项 | 带腐化效果的选项以暗红墨色与裂纹框标记 | 腐败纹路 1 级以上出现（corruption-system） |

## 3. 任务追踪

| 元素 | 位置 | 内容 | 状态 |
|---|---|---|---|
| 主目标 | 右上 | 当前主线任务目标（单一主目标） | 常驻 |
| 支线 | 右上（主目标下方） | 进行中支线列表 | 独立显示，不与主目标混合 |
| 区域名 | 主目标上方 | 当前区域中文名（归墟出口/墟门…） | 区域切换时短暂显示后淡出 |

任务目标文案引用 `xumen-prologue-quests.md` 的步骤描述；「任务目标始终只有一个主目标，支线单独显示」为验收项。

## 4. 系统界面

| 界面 | 用途 | 关键状态 |
|---|---|---|
| 证据板 | 线索收集进度「线索 N/3」 | 凑齐解锁特殊对话与机关解法（quest-structure-differentiation 4.2） |
| 残响图鉴 | 区域残响收集 | 每区域独立页，集齐解锁隐藏真相；残响条目为短文本或 10–20 秒演出 |
| 对话窗 | 剧情对话 | 底部纸卷样式；说话人名牌 + 五行语气染色（narrative-differentiation 第 7 节） |
| 检查点交互 | 墟门检查点 | 复活确认 + 快速返回选项（xumen-prologue-return-paths 4.2） |
| 死亡重试 | 全屏淡入 | 「按 R 从最近检查点重试」；不重复发放奖励 |

## 5. 字体与配色规范

- 字体：中文黑体/明朝体混合——正文用明朝体（宋体类），数字与状态用黑体；正式素材阶段锁定字体文件，先用系统字体占位。
- 主色：旧纸白（#E8DFC8）、墨黑（#1A1712）、朱砂（#A33B2E，警示/敌人）。
- 元素色（与地域效果表一致）：木深绿、火朱红、土黄褐、金银灰、水深青——UI 元素色只用于对应元素内容，不混用。
- 腐化色：暗红（#5E1F14）+ 裂纹纹理，用于污染选项与腐败纹路相关显示。
- 闪光限制：所有高亮动画不得超过每秒 3 次全屏闪烁；关闭「减少闪光」后仍不得有频闪风险色块。

## 6. 无障碍

- 三项开关（减少闪光/屏幕震动/粒子密度）全局生效，UI 动画同步降级。
- 稳定条、架势、元素资源同时有颜色与形状/文字提示。
- 所有关键战斗提示（破稳、失衡、处决）附带音效通道（见 audio-spec）。
- 对话可选「自动播放」与「关闭字幕特效」。
