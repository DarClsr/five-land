# 世界年表

## 1. 使用说明

本文档是全部剧情时间锚点的唯一来源。写作任何涉及时间的剧情、台词或设定时必须对照本文档，防止「木境数十年无凋零」与「五衡院建立时间」等锚点互相矛盾。文档只记录已确认的时间点；新增时间锚点先在此登记再使用。

## 2. 纪年约定

- 世界采用「衡历」，以五衡院建立之年为元年。
- 本文档采用「衡历 N 年」与「序章前约 N 年」两种表达；序章发生年为**衡历 812 年**。
- 凡人寿命与五境平均寿命相当（约 60–80 岁），异类与容器不受此限。

## 3. 纪元划分

| 纪元 | 时间 | 世界状态 |
|---|---|---|
| 太古 | 衡历之前（不可考） | 五行循环完整，归墟正常分解旧物；五境各自发展，无统一机构 |
| 衡立纪 | 衡历 1–300 年 | 五境统治者建立五衡院，开始向归墟倾倒；初期的确为应急措施 |
| 超载纪 | 衡历 300–600 年 | 归墟逐渐超载，腐败初现；倾倒从应急变成惯例，真相开始被制度化隐瞒 |
| 容器纪 | 衡历 600–800 年 | 五衡院秘密实施「容器计划」；第一代容器（引渊人）失败并被抹除 |
| 当代 | 衡历 800–812 年 | 腐败全面反噬五境，异类增多；无央诞生，序章开始 |

## 6. 一致性约束

- 台词中的时间表述优先用「年表对齐表」的口径（如「数十年」「数百年」），避免精确到具体年份。
- 新写剧情若需新增时间点，先在本文档第 4 节登记，再写入具体章节文档。
- 第一代容器的失败与「无央诞生」之间相隔约 140 年，引渊人等待的动机需能解释这段等待（其残响依赖归墟残余维持）。
