# 叙事差异化与写作原则

## 1. 目标

本文档是《世界观与剧情规划》（`docs/world-and-story.md`）与《角色与任务规划》（`docs/characters-and-quests.md`）的写作层补充：不修改已有设定，只约束剧情写作执行标准，规避三类俗套：

- 「觉醒的容器」俗套：近十年 JRPG 常见的「人造人寻找自我」配方。
- 自然主义鸡汤：把「恢复循环、接受死亡」写成纯正能量。
- 线性揭示：信息只加码不翻盘，玩家无第二层反转。

## 2. 容器身体化写作

无央的身体是归墟的延伸、五境的垃圾桶。把「容器」写成具体的身体经验，而不是抽象哲学问答：

- **裂纹 = 垃圾分类的痕迹**：每回收一枚碎片，她「消化」一类废弃物；裂纹的颜色与位置对应碎片属性（土=黄绿、水=深青、火=朱红、金=银灰、木=青绿）。
- **记忆味觉**：吸收记忆时尝到味道——水境碎片咸涩如眼泪，火境碎片是灼烧的烟味，木境碎片带苔藓的湿气。
- **模仿痕迹**：无央模仿他人的情感（设定已有），写作时让对话选项偶尔出现「她正在像某个人说话」的痕迹——阿砾教她回答守门人，沈汐教她说「我」。只做语气染色与少量专属台词，不锁定个性。

应用：所有无央台词写作需回答「此刻她在模仿谁」。

## 3. 第三立场

- 现状只有两条路线：恢复循环（引渊人）与维持封印（太衡）。
- 引入第三条路线的代表人物：**异类共同体领袖**（候选：槐娘或缄伯），在中段（火境或水境）登场。
- 诉求：「我们不要求世界变回从前，我们要求世界接受我们。」
- 与「恢复循环」产生真实冲突：恢复后的世界可能不需要异类——循环重新运转后，异类是否是必须清除的异常？
- 影响：结局判定「共生」不再只是「保护异类」，而是「为异类在世界里争取位置」。真结局因此从「全都要」变成「为少数人争取权利」，深度完全不同。

## 4. 第二层反转

- **引渊人 = 上一代容器的人格，他的「拯救世界」计划里，无央只是新的身体。** 文档已埋「形体逐渐与无央相似」，水境发现「上一代容器被抹除」时引爆：玩家突然意识到引导者一直在计划让无央成为「他」。
- **五衡院最初可能是对的**：归墟超载前，向归墟倾倒确实是应急措施。「谎言是从什么时候开始的」——如果玩家发现五衡院的初衷正当，只是拖了太久，太衡的道德灰度直接拉满。
- 放置原则：不改变主线结构，只改变揭示顺序与对白。两条反转均不新增任务。

## 5. 异类的代价：共生不是无条件的

- 部分异类真的危险、真的不值得救，且玩家无法提前分辨。
- 示例：某条异类支线中，玩家一路保护的角色，结局揭示他正是失踪送葬队惨案的凶手——执念是用来掩盖罪行的。
- 目的：让「共生」轴本身有成本，玩家认真对待每一次「救不救」，而不是无脑全保。

## 6. 封渊也有幸福

- 代价写作原则：「维持」与「恢复」都必须有值得被爱的理由。
- 封渊结局：玩家帮过的支线 NPC 一家在稳定秩序下平安活着，片尾裂缝才出现——维持旧秩序不是纯惩罚，玩家在终局前有真实理由动摇。
- 对应地，恢复循环的代价镜头（见 `docs/story-cost-beats.md`）让「恢复」也不是纯奖励。两条路都有血有肉，选择才痛。

## 7. 对话五行语气

- 无央的对话选项按当前「最亲近人格」轻微染色：土境阶段像阿砾（务实、克制），水境阶段像沈汐（柔和、停顿）。
- 实现：选项文本带语气标签（像阿砾 / 像沈汐 / 像自己），不同标签对应少量专属台词。
- 约束：语气染色不改变选项的实质内容与任务结果，只改变表达。

## 8. 与现有文档的关系

- 本文档为写作执行标准，不推翻 `world-and-story.md` 与 `characters-and-quests.md` 的既定设定。
- 若后续细化某境剧情时与本文档冲突，以本文档为准并回改原文档，保持单一声源。

## 9. 验收标准

- [ ] 无央全部台词可回答「此刻她在模仿谁」。
- [ ] 中段存在第三条路线的代表人物及其与「恢复循环」的冲突场景。
- [ ] 水境揭示「上一代容器被抹除」时，引渊人反转被玩家理解而非被台词解释。
- [ ] 至少一条异类支线包含「不值得救」的代价设计。
- [ ] 封渊结局存在一个具体的幸福家庭画面。
