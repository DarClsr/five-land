## 8. 验收标准

- [ ] 每个资产按清单生成并验收（透明、边缘、锚点、比例）。
- [ ] 可交互物（石灯/送葬车/封印桩/墓门/检查点）在灰盒阶段就有可辨识占位。
- [ ] 特效位不阻塞 P2 灰盒，P4 统一接入。
- [ ] 新场景道具先入清单再入素材批次。
