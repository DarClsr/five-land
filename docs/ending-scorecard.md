# 结局计分器全局表

## 1. 三轴定义

| 轴 | 定义 | 判定方式 |
|---|---|---|
| 循环 | 是否让五境重新接受相克、死亡与自然损耗 | 累计循环点 |
| 共生 | 是否帮助仍保有人格的异类 | 累计共生点 |
| 羁绊 | 是否完成五位关键角色个人任务 | 5 项布尔 |

判定规则（world-and-story 第 7 节 Mermaid 的数值化）：

```text
if corruption_points >= 15 -> 无相
else if 循环点 < 6 -> 封渊
else if 羁绊 == 5/5 and 共生点 >= 8 -> 共生·真结局
else -> 归环
```

## 3. 阈值依据

- 循环点上限：6 主线（+12）+ 代价镜头（+5）+ 生活支线（+5）+ 土境支线（+1）= 23；封渊线 <6 意味着多数地域未恢复相克。
- 共生点上限：8；真结局要求 ≥8 即全部异类支线完成。
- 羁绊：5 位角色任务全完成才满足。
- 无相线：corruption_points ≥15（corruption-system 第 6 节）。

## 4. 存档状态键 schema

```text
# 计分轴
cycle_points              # 0–23
symbiosis_points          # 0–8
bond_ali               # bool 阿砾
bond_qingtan           # bool 青檀
bond_lizhao            # bool 离照
bond_bairan            # bool 白刃
bond_shenxi            # bool 沈汐
# 吸收与选择
corruption_points         # 0–30
pollution_choice_count    # 污染选项次数
# 流程
prologue_step / prologue_complete       # 序章
side_blank_grave_choice / side_downward_lantern_choice  # 序章支线
cost_beat_<region>_seen   # 代价镜头已看
```

序章阶段不建立全局计分器（xumen-prologue-quests 第 6 节），但状态键命名从现在开始按本 schema 预留，第二境完成后接入。
