# 《Five Land》术语表

## 1. 使用说明

本文档是全部设计文档的术语唯一来源。新文档、新台词、新 UI 文案必须使用本文档的定义与命名；发现术语漂移时，回改相关文档并更新本文档。防止「无央/无咎」类命名分歧再次发生。

## 3. 战斗术语

| 术语 | 定义 | 相关文档 |
|---|---|---|
| 五行稳定 | 敌人的元素平衡数值；相克攻击削减，归零进入失衡 | combat-system-spec |
| 失衡 / 处决窗口 | 稳定归零后的 2.5 秒（首领 2.0 秒）硬直，期间受击伤害 ×2.0 | combat-system-spec |
| 元素资源 | 每套架势独立的资源池：土·镇力、水·流转、木·生机、火·薪火、金·契力；相生攻击产出，架势技能消耗 | combat-system-spec |
| 架势 | 无央的五行战斗姿态；序章开放土、水，全量五套 | combat-system-spec |
| 破稳 | 用相克攻击削减五行稳定至归零 | combat-system-spec |
| 处决 | 失衡窗口内消耗 50 资源触发的终结动作；普通敌人直接处决，首领受 ×4.0 终结伤害 | combat-system-spec |
| 执念闪现 | 处决前约 1 秒闪出敌人执念画面的演出 | combat-narrative-fusion |
| 净化 / 吸收 | 处决时的二选一：净化获得资源与执念消散；吸收获得更多资源与腐化纹路 | combat-narrative-fusion |
| 环境稳定值 | 环境对象（火墙、藤桥、铁门等）的稳定值，相克削减后改变状态 | combat-narrative-fusion |
| 相生循环 | 连续相生切换（木→火→土→金→水→木）触发的循环状态，架势技能消耗减半 | combat-narrative-fusion |
| 腐败纹路 | 吸收腐败在无央身上形成的 0–3 级裂纹外观 | combat-narrative-fusion |
| 本源感应 | 常驻探索技能，按住感应键高亮五行失衡点 | combat-narrative-fusion |
| 五行稳定（环境） | 见「环境稳定值」，避免与敌人稳定值混淆 | combat-narrative-fusion |
| 场景同伴 | 非战斗单位的同行者能力：阿砾读墓契、青檀诊断、白刃拆机关、离照点灯、沈汐读记忆 | combat-narrative-fusion |

## 7. 命名规范

- 主角：**无央**（全库统一，禁止使用「无咎」）。
- 文档文件：kebab-case（`docs/combat-system-spec.md`）。
- 场景与脚本：snake_case（`scenes/hd2d_test.tscn`、`player_controller.gd`）。
- Godot 节点：PascalCase（`MainCamera`）；脚本成员：snake_case。
- 任务 ID：序章主线 `FL-P00` 起、支线 `FL-S01` 起；章节前缀：木境 `MU-`、金境 `JI-`、火境 `HUO-`、水境 `SHUI-`、土境深层 `TU-`（主线 `-P01` 起，支线 `-S01` 起），稳定不变。
- 境内节点与首领名以本文档第 5 节与 `docs/monster-bestiary.md` 为准。
