# 无央 HD-2D Q 版像素八方向渲染规范

## 美术方向

- 角色必须是国风、东方武侠奇幻风格；其他 RPG 仅用于研究固定镜头、方向切换和画面层次，不作为服装设计参考。
- 无央使用约三头身 Q 版比例，保持黑色高马尾、贴身交领、露肩小型护甲、腰封、分片长摆和双武器辨识点。
- 正式运行素材采用 128×128 RGBA 像素单格，清楚像素簇、克制色块和统一脚底锚点；禁止把高清立绘直接缩小当作运行素材。

## 资产契约

- 身份设计参考：`docs/art/references/juse-character-turnaround-v1.png`，只锁定黑色高马尾、黑红国风服装和双匕首。
- 当前正式运行方向帧位于 `assets/characters/wuyang/pixel/`；`wuyang_idle_screen_s_v1.png` 是正向母版，其余七张只对应各自屏幕方向。
- 固定游戏相机俯角、角色屏幕比例、脚底基线与左上主光方向；所有方向帧必须在同一合同下制作。
- 输出 `idle`、`walk` 等透明帧或图集；默认单格 128×128。动作需要更宽运动空间时统一扩大整套单格，不单独拉伸某一帧。
- 行顺序固定为：北、东北、东、东南、南、西南、西、西北。
- 黑红衣摆和腰间饰物不对称，因此八个方向均需独立验收，不使用水平镜像作为最终素材。
- 所有单格共享中心锚点，Godot 中只调整一次 `AnimatedSprite3D` 的落脚位置。

## 制作顺序

1. 先完成正向 Q 版像素待机单帧，在 1280×720 实机镜头中确认身份、尺寸和融合感。
2. 身份稳定后生成八方向静态集，逐方向检查高马尾、衣摆、肩甲和武器侧别。
3. 先制作待机和移动，再制作攻击、闪避、受击与死亡；静态身份未通过前不批量生成动画。
4. 在 3D 场景中检查 Nearest 采样、薄雾、遮挡和接触阴影，不强制制作像素法线贴图。
5. 通过后放入 `assets/characters/wuyang/pixel/`；方向命名是运行时与测试共同遵循的合同。

## 运行时约定

移动输入先按屏幕空间划分八方向，再转换为相机相对的三维移动向量。朝向动画不再根据世界坐标或旧四方向图片推断，因此按上、下、左、右以及四个斜向时，移动与人物视觉朝向保持一致。

正式运行只使用 Q 版像素 `AnimatedSprite3D`，不保留旧高清验证帧或可见/隐藏的 3D 人物兼容路径。
