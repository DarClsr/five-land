## 2. 评测方法

动画工具最容易出的问题不是画得丑，而是**看起来在动、实际没有迈步**。因此判定不靠肉眼，用两个量化指标：

- **脚部跨距**：取精灵底部 20px 内不透明像素的横向包围宽度。真实步态会在「张开—并拢—张开」之间循环，跨距最大值 / 最小值应大于 1.6。
- **轮廓像素波动**：整帧不透明像素数的相对变化。双腿真正分开时波动应超过 8%。

注意不要用 RGB 逐帧差异判断腿部运动。无央下半身是黑袍，明暗对比极低，几何上腿在动、RGB 差异却很小，会得出完全相反的错误结论。**判定必须基于 alpha 轮廓，不是颜色。**

## 3. 实测数据

### 3.1 Retro Diffusion（`rd_advanced_animation__walking`）

输入 `assets/characters/wuyang/pixel/` 的已批准八方向原画，逐方向 img2img，输出 4×2 网格、128px 单元、透明背景。

| 方向 | 脚部跨距（8 帧，px） | 跨距比 | 判定 |
| --- | --- | --- | --- |
| 正面 `s` | 34 / 40 / 23 / 20 / 17 / 14 / 13 / 39 | 3.08 | 通过 |
| 侧面 `e` | 30 / 43 / 43 / 33 / 17 / 24 / 39 / 42 | 2.53 | 通过 |

侧面可见明确的前后腿交替、重心起伏、马尾与持刀手臂随步伐摆动。形象要素（高马尾、红发绳、护肩、双匕首、红腰封、黑红袍配比）全程保持。

### 3.2 Meowa `animate-run`

| 指标 | 实测 | 判定线 | 结果 |
| --- | --- | --- | --- |
| 帧间形象差异 | 12–17 / 255 | 越低越好 | 通过 |
| 轮廓像素波动 | 3.5% | > 8% | **不通过** |
| 腿部区域差异 / 整帧差异 | 0.55 | > 1.2 | **不通过** |

腿部是全图**变化最小**的区域，与真实步态完全相反，且无周期结构；改用 `--animation-type walk` 无改善。产出是无结构抖动，不是步态。该结论推测适用于同类 img2img 动画模型在低分辨率 Q 版精灵上的表现，非 Meowa 独有。

### 3.3 Meowa `character-multi-view-run`

一次调用出全部八方向，仅 4 credits，**组内身份一致性极好**——八张之间没有漂移。

但与已批准原画对比存在系统性偏差：头身比偏高（约 3.5–4 头身 vs 原画 3 头身）、袍色偏棕、背面视角丢失头发细节。适合从零立形象，不适合给已定稿的角色补方向。

## 4. 采用的生产流程

Retro Diffusion 是 **img2img 逐方向**的，每个方向都锚定在自己那张已批准原画上，因此不存在跨方向漂移——这是它相对「一次生成八向」类工具的根本优势。

```
assets/characters/wuyang/pixel/wuyang_idle_screen_{n,ne,e,se,s,sw,w,nw}_v1.png
        │  每张一次 rd_advanced_animation__walking（$0.14）
        ▼
8 行 × 8 帧 走路图集
        │  DirectionalSpriteFrames.build()
        ▼
player_controller.gd 把 build_static() 换成 build()
```

待机动画不走生成路线，沿用 `player_controller.gd` 中已实现的程序化呼吸与浮动，成本为零。真图集接入后这套程序化位移仍然叠加，用于增强手感，两者不冲突。

### 4.1 接口要点

- 端点 `https://api.retrodiffusion.ai/v1`，鉴权头 `X-RD-Token`，密钥存于 `.env` 的 `RD_API_KEY`（已被 `.gitignore` 忽略，**禁止提交或粘贴到对话中**）。
- `/status` 是公开端点，**带鉴权头会返回 500**，查询时不要附带。
- 请求偶发 500，需要重试；异步任务用 `POST /v1/inferences` 加 `"async": true`，再轮询 `GET /v1/inferences/tasks/{task_id}`。
- `"check_cost": true` 是**免费试算**，正式调用前先问价。
- `input_image` 是不带 `data:` 前缀的 base64 PNG，且**必须是不透明 RGB**；把原图合成到白底再编码，配合 `remove_bg: true` 取回透明。
- `width` / `height` 必须与起始帧一致；`rd_advanced_animation` 系列支持 32–256px。
- `return_spritesheet: true` 直接拿 PNG 图集，省去拆 GIF。

### 4.2 其他可用样式

- `rd_animation__four_angle_walking`：$0.07，原生四方向行走，但固定 48×48。
- `rd_animation__8_dir_rotation`：$0.25，原生八向且支持 5 张参考图，固定 80×80。

两者分辨率都低于本项目的 128px 合同，仅在需要低成本试探时使用。
