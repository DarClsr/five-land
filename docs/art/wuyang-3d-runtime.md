# 无央 3D 人物实验归档

## 决策状态

- 直接显示 GLB 的角色路线已停止，不作为正式美术方向。
- 正式运行采用“风格化低多边形 3D 世界 + 高清八方向 2D 角色 + 固定斜俯视镜头”。
- 现有 v3–v7 Blender/GLB 文件是历史实验，只用于验证控制器朝向、比例、碰撞和动画接口；不得继续当作正式角色精修底模。
- 新角色素材以 `docs/art/character-asset-contract.md` 和 `docs/art/wuyang-hd2d-render-contract.md` 为准。

## 可复用技术成果

- 保留屏幕八方向到三维移动向量的映射。
- 保留 `idle`、`walk`、`attack`、`dodge`、`hurt` 与 `death` 的动画状态命名。
- 保留角色胶囊碰撞体、受击盒、攻击盒和地面定位逻辑。
- 可使用不可见的简化 3D 代理投射环境长阴影，但代理不得作为玩家可见外观。

## 不再继续的工作

- 不再用程序化基础几何拼装脸、头发和服装。
- 不再为正式画面精修现有 Quaternius 角色底模。
- 不再将三视图直接转换为运行时 GLB 作为默认方案。
