# 角色高清素材合同

## 范围

首批素材覆盖无央、阿砾和一名普通腐化者，用于墟门序章灰盒中的角色比例、对话和战斗验证。

## 共通视觉规范

- 表现：高清国风角色插画，以清晰线稿、克制赛璐璐明暗和成熟比例为基础，用旧版画、纸扎、墓契、绳结与民俗禁忌补充东方志怪感；不使用像素风、幼态 Q 版或通用奇幻护甲。
- 视角：固定 3/4 俯视正面，匹配当前 HD-2D 镜头（约 30–40° 俯角）。角色必须能看到头顶与肩部透视压缩，肩宽大于胯宽，双脚明确接地、脚底不悬浮；禁止正面平视立绘角度。
- 调色：角色固定白发、青色瞳孔；基础形态以墨黑、灰白、旧纸黄为主，五行形态可使用各自的高识别色，但控制大面积荧光和金属高光。
- 光向：左上方冷色月光，轮廓像被阴间纸灯照亮，土境黄褐反光仅作辅助。
- 边缘：轮廓平滑、透明边缘干净，发丝和武器不得出现白边、黑边或背景残留。
- 背景：透明，不含地面、投影、文字、边框或装饰底板。
- 方向：本批只确认正面身份与动作；多方向在角色定稿后生成。

## 静态合同

- 能力：Meowa `hd-gen-run`。
- 预设：使用 `hd_char_5`「淡雅国风人物立绘」，以成熟版无央参考锁定身份和绘制方式。
- 固定输出：2K 任务生成两张 1024×1024 透明 PNG 候选；只将验收候选放入游戏资产目录。
- 姿势：放松待机，脚部可见，身体不被裁切。
- 构图：单人、居中、轮廓完整，四周保留透明边距。

## 角色设计

### 无央

- 女性人形容器，成熟年轻女性比例，动作轻盈、克制而具有攻击性。
- 醒目的长白发与青色瞳孔是所有形态不可改变的身份锚点；发尾呈宣纸般分束，表情安静、警觉。
- 基础形态穿墨青与灰白交领短袍、窄袖内衫、长裤与布靴，带少量纸扎硬折、非对称衣摆和褪色朱砂绳。
- 基础形态携带无元素特效的「归墟双匕」，以轻装刺客作为基础战斗身份；五行服装与武器按系统独立替换，详见《五行装备与解锁设计》。
- 五行变体必须保留脸型、发型主轮廓、眼色和整体身高，只改变束发饰件、外层服装、护具与武器。
- 剪影关键词：长白发、双细辫、青瞳、成熟国风、交领叠穿、志怪小物、清晰双匕轮廓。

### 阿砾

- 男性土境送葬人，身形结实，姿态克制。
- 深棕短发，有风尘感，神情务实而警惕。
- 黄褐与青灰叠层送葬袍，腰间悬挂墓契木牌、绳结和折叠白布。
- 肩部有短披风或防尘护肩，不使用华丽官服轮廓。
- 剪影关键词：宽肩、墓契木牌、绳结、送葬职业感。

### 普通腐化者

- 原为土境送葬队员，仍保留人形和残破工作服。
- 身体一侧被青黑水渍与错位石脉覆盖，不使用普通黑雾。
- 肩颈轻微错位，一条手臂较重，形成可读的近战攻击侧。
- 剪影关键词：不对称、石脉、潮湿衣摆、依然可辨认的人类职业。

## 动画合同

- 能力：优先使用 Meowa `animate-run`；精确攻击姿势必要时使用 `keyframes-run`。
- 源角色内容：使用验收后的 1024×1024 透明高清母版，不转成像素图。
- 动画画布：按动作方向增加透明运动空间，不拉伸角色；待机可沿用方形画布，移动、闪避和攻击在首次试产后锁定统一规格。
- 锚点：双脚中点统一位于单元画布中的固定基线，所有动作保持一致。
- 帧数：普通循环和单次动作默认 8 帧。
- 输出：优先透明 spritesheet；待机与移动必须无跳变循环。
- 镜头：锁定，角色比例、调色板和轮廓不变。

### 首批动作

| 角色 | 动作 | 类型 | 要求 |
|---|---|---|---|
| 无央 | 待机 | 循环 | 轻微呼吸、衣摆小幅摆动 |
| 无央 | 移动 | 循环 | 双腿前后分开，向前行走，脚底不漂移 |
| 无央 | 攻击 | 单次 | 使用归墟双匕完成一次清晰交叉斩并收势 |
| 阿砾 | 待机 | 循环 | 呼吸、肩部抑制性起伏、木牌轻摆 |
| 腐化者 | 待机 | 循环 | 身体不对称抽动，不使用黑雾 |
| 腐化者 | 移动 | 循环 | 拖拽重臂向前行走 |
| 腐化者 | 攻击 | 单次 | 重臂明确后拉并向前横扫 |
| 腐化者 | 受击 | 单次 | 向后短促硬直，轮廓不破碎 |
| 腐化者 | 死亡 | 单次 | 下沉跪倒并石化静止 |

## Godot 导入规范

- 位置：`assets/characters/<character>/`，只放入已验收的最终文件。
- PNG 与 spritesheet 使用无损导入或高质量 VRAM 压缩、Linear 过滤、开启 mipmap，并保留透明边缘修复。
- 高清角色通过面向镜头的 `AnimatedSprite3D`/`Sprite3D` 显示，使用 `assets/shaders/hd_sprite_unfogged.gdshader`（`diffuse_toon` 受光 + 卡通描边），角色需要真正参与场景光照产生明暗体积，禁止改回无光照材质；地面、建筑和投影同样参与 3D 光照，保持明暗基调一致。
- 立体化要求（防止贴图沦为「纸片人」）：每个角色的每一帧静态/动画贴图必须配一张同名法线贴图（`_n` 后缀，如 `wuyang_idle_iso_front_right_n.png`），用于让定向光在角色身体上产生跨部位的明暗渐变，而不是整块平面同步变亮变暗；法线贴图由本地工具（如 Laigter）从已验收贴图批量生成，不占用 Meowa 生成额度。
- 当前 1280×720 验证镜头下角色目标高度约 100–120 屏幕像素。
- 不提交 Meowa 任务清单、参考图、中间姿势、遮罩或调试文件。
