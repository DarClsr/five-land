# 任务结构差异化设计

## 1. 目的与原则

当前五境主线共用同一模板（调查腐败痕迹 → 探索遗迹 → 击败守护者 → 处理本源），玩家玩完木境即可预判金境。本设计解决结构同质化问题。

原则：

- 设定对称，任务不对称：每境拒绝一种相克的设定保持统一，但任务骨架必须每境不同。
- 任务类型从该境设定里长出来，不引入与设定无关的玩法（如通用潜行、通用解谜）。
- 序章保持「线性教学 + 首领战」骨架不变，它是已验证可落地的垂直切片。
- 新增内容不扩展主线任务数量，只改变任务的组织方式与表现。

## 2. 五境任务骨架

| 境 | 现模板 | 建议骨架 | 设定依据 | 任务类型变化 |
|---|---|---|---|---|
| 木境 | 调查→探索→打 | **仪式**：修剪母树是玩家操作的分段仪式，每段付出代价，守护者战只是其中一段 | 金克木的「修剪」是循环行为，不是一次战斗 | 从「击败」变成「亲手执行并承受」 |
| 金境 | 同上 | **潜入与破坏**：利用身份铃伪装成不同职业潜入天衡塔，身份铃对应五行（工匠=金、医者=木） | 白铸城邦以职业替代姓名，身份铃即通行凭证 | 潜入伪装的理由完全来自设定 |
| 火境 | 同上 | **断后与护送**：不熄炉破裂后腐败涌入，任务变为护送巡火队与民众撤离，战斗是生存战而非清场 | 中局反转的戏剧性需要任务类型转换支撑 | 从「进攻」变成「保护」 |
| 水境 | 同上 | **记忆潜行**：沉镜宫关卡由他人记忆构成，玩家操控无央在记忆中的投影，失败代价是被记忆同化 | 水境主题是「谁的记忆」，任务形式必须用记忆本身 | 从「探索空间」变成「穿越记忆」 |
| 土境深层 | 同上 | **证词对决**：祖城裂开后不是战斗，而是阿砾在公开场合对墓契宗族的证词交锋，玩家用前几境收集的证据逐条反驳 | 土境主题是「被删除者的历史」，证据是唯一武器 | 从「战斗」变成「对峙」 |

五种骨架各有一次验证点：木境仪式承接教学（相生循环），金境潜入承接身份系统，火境生存战承接战斗规格的处决与资源，水境记忆潜行承接残响系统，土境证词对决承接证据系统。

## 3. 支线模式多样化

### 3.1 问题

现规划中 12 条支线几乎全部是「对话二选一 + 记录一个倾向」，玩家在第三、四条支线后开始机械选择。

### 3.2 三种新模式

| 模式 | 定义 | 适用示例 |
|---|---|---|
| 时序决定 | 不做选择也是选择：玩家搁置支线、推进主线后再回来，世界已自行变化 | 苔七的寄生花若搁置两个主线任务，已自然凋零，苔七自己做了决定 |
| 行为判定 | 无显式选项，由战斗行为判定结果（是否误伤、是否用相克） | 槐娘线：战斗中误伤孩子 vs 精准破稳，决定她对玩家的态度 |
| 复合选择 | 选项有成本：可「全都要」但付出代价 | FL-S01：写回宗族与共同墓位可同时做，但损失一部分居民支持 |

### 3.3 现有支线改造建议

| 支线 | 现模式 | 建议模式 | 说明 |
|---|---|---|---|
| FL-S01 一块空墓位 | 二选一 | 复合选择 | 增加「同时做」的代价选项 |
| FL-S02 灯不能朝下 | 二选一 | 保留 | 序章教学需要明确二元选项 |
| 苔七·借来的春天 | 二选一 | 时序决定 | 搁置即结局，与「循环」轴衔接 |
| 槐娘·长在屋中的人 | 二选一 | 行为判定 | 战斗行为替代对话框 |
| 烬童·最后一句话 | 二选一 | 复合选择 | 真实遗言可交付 + 保留安慰版本，但两者互斥消耗 |
| 泊生·不存在的童年 | 二选一 | 时序决定 | 归还记忆前可先完成另一条水境支线，记忆归属随之改变 |
| 其余五条 | 二选一 | 保留或按需调整 | 不强制全部改造，保持一半经典二元选择 |

## 4. 证据与残响系统

### 4.1 信息载体

五境全部使用不同媒介记录「不该被记住的东西」，这是本作独有的世界资产：

| 载体 | 境 | 承载内容 |
|---|---|---|
| 墓契 | 土 | 命契、墓位、家族归属 |
| 水镜 | 水 | 公共与私人记忆 |
| 余烬遗言 | 火 | 死者最后一句话 |
| 身份铃 | 金 | 职责与工作年限 |
| 寄生花声音 | 木 | 死者声音的重复 |

### 4.2 证据板（轻量实现）

- 收集的线索进入证据板，显示「线索 N/3」进度。
- 某些对话选项与机关解法需要凑齐证据才解锁；不做推理 UI，只做进度 + 特殊对话。
- **证据板为全局单页**（跨区域可用），按区域分组展示。跨区域交织线索（如木境的走私刃具、金境的运输记录）必须落证据板条目——交织点的可发现性依赖系统替玩家记忆，不依赖玩家记住 10 小时前的台词。
- 证据来源覆盖：调查物、支线、战斗处决的执念闪现（见《战斗与叙事融合规格》）、NPC 对话。
- 土境「证词对决」直接消费证据板内容，让序章起的概念在终章前兑现。

### 4.3 残响图鉴（收集系统）

- 每个区域存在可收集的「残响」——死者或异类的最后记忆片段。
- 集齐一个区域的全部残响，解锁该区域隐藏真相（如木境 7 段残响解锁「母树第一任祭司」的记忆，揭示母树如何开始）。
- 残响图鉴是叙事系统不是成就系统：内容为短文本或 10–20 秒演出。
- 序章放置 2 个残响收集点作为系统验证，不进入主线。

## 5. 聚落状态机

- 区域主线完成后，聚落进入新状态：场景变化（落叶、星空，已有规划）、NPC 对话、NPC 去留、商店内容均改变。
- 状态至少三态：处理前 / 恢复相克后 / 吸收腐败后（吸收态可选做）。
- 玩家能看见自己的行为改变世界，这是体验感的核心来源。
- 聚落状态机与结局计分器解耦：状态变化只影响当下体验，不计分。

## 6. 序章落地建议（P2 范围）

- 教学主线保持清爽：10 个教学点已满，不再向主线塞内容。
- 非强制内容三项：
  1. 归墟出口与墟门各 1 个残响收集点（验证残响图鉴）。
  2. 1 个可选 NPC 日常对话（砚婆或小烛，验证聚落对话状态）。
  3. 1 个环境破稳机关：送葬道一段火墙用水架势浇灭，可绕开一场战斗（验证环境五行，见《战斗与叙事融合规格》）。
- 三项均不影响主线通过，均可被玩家错过。

## 7. 验收标准

- [ ] 五境主线任务骨架各不相同，且每种骨架的玩法直接来自该境设定。
- [ ] 支线至少三条采用新模式（时序决定 / 行为判定 / 复合选择）。
- [ ] 证据板与残响图鉴在序章有最小可用版本，五境共用同一套规则。
- [ ] 聚落状态机在木境完成第一次完整验证。
- [ ] 序章非强制内容不打断教学节奏，主线不做支线也可连续完成。
