# 音乐与音效主题表

## 1. 定位

本文档定义全流程的音乐主题与音效分类，是 `asset-prompt-guide.md` 第 7 节音效方向的系统化扩展。音频在 P4 用 Meowa `audio` 模块生成；本文档是生成输入与验收依据。

## 3. 音效分类表

### 3.1 战斗

| 类别 | 内容 | 要求 |
|---|---|---|
| 五行命中 | 木=分叉藤响、火=爆燃、土=尘闷响、金=金属脆响、水=水花 | 克制命中音更高亢，相生命中更绵长 |
| 破稳/失衡 | 裂纹崩裂 + 破甲声 | 与稳定条三段颜色对应音高递增 |
| 处决 | 执念闪现=记忆倒放 + 杂音；净化=消散风铃；吸收=吞咽低频 | 二选一两个方向必须可区分 |
| 闪避/受击/死亡 | 气流、闷响、石化 | 与素材合同动作表配套 |

### 3.2 环境（ambience，见 entity-definition-guide 声音环境表）

归墟倒放风声、墟门铰链、送葬道纸页、封印庭院低频共鸣、木境树冠风声、火境热浪低鸣、金境齿轮、水境雨幕、土境沙尘、归墟五行抵消嗡鸣。

### 3.3 UI

对话翻页（纸页声）、选项确认（印章落响）、任务更新（铃）、残响收集（记忆倒放短音）、检查点（石磬）。

## 4. 命名与文件规范

- 目录：`assets/audio/music/`（区域/角色/首领）、`assets/audio/sfx/`（combat/environment/ui）。
- 命名：`music_<region>_<name>.ogg`、`sfx_<category>_<name>.ogg`。
- 格式：音乐 OGG 44.1kHz，音效 WAV/OGG 短文件。
- 音量分层：音乐 -12dB 基准、环境 -18dB、战斗音效 -6dB、UI -10dB。
