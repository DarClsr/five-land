# 战斗与叙事融合规格

## 1. 定位

本文档是《五行战斗系统总规格》（`docs/combat-system-spec.md`）的扩展篇，将战斗系统与世界观叙事融合，形成本作区别于一般属性克制游戏的差异点。不修改既有数值表；与既有规格冲突时，以本文档为准并回改既有规格。

## 2. 处决 = 取回记忆

### 2.1 执念闪现

- 破稳处决（见战斗规格 3.3）触发时，处决演出前插入约 1 秒的「执念闪现」：画面闪出该敌人执念的画面（妻子、未送出的信、被凿去的名字）。
- 普通腐化者与精英都有闪现；首领战只在最终终结时闪现一次。
- 演出不打断节奏：闪现期间时间暂停但输入队列保留，玩家在闪现结束后立即二选一。

### 2.2 净化 / 吸收二选一

| 选项 | 效果 | 叙事代价 |
|---|---|---|
| 净化 | 获得 30 对应资源，执念消散 | 无 |
| 吸收 | 获得 60 资源与一层短期强化，执念进入无央 | 身体裂纹加深一级、腐化纹路推进（见第 5 节）、NPC 态度变化 |

- 吸收按钮与净化按钮为两个独立键，避免「确认框」式打断。
- 处决选择计入结局计分器的「吸收倾向」，与既有「无相」判定衔接。
- 序章实现简化版：仅首领战处决出现二选一，普通腐化者自动净化。

## 3. 环境五行（环境稳定值）

### 3.1 概念

- 环境对象（火墙、藤桥、铁门、石墙、水面）拥有与敌人稳定值同语言的「环境稳定值」。
- 相克攻击或对应架势技能削减环境稳定，归零后对象改变状态（熄灭、断裂、熔断、开裂、冻结）。
- 显示与敌人稳定条同语言：对象表面裂纹、变色与音调提示。

### 3.2 五境用例

| 相克 | 用例 | 结果 |
|---|---|---|
| 水克火 | 浇灭岩浆 / 火墙 | 开出新路，序章送葬道火墙可绕开一场战斗 |
| 土克水 | 冻结水面 / 泥沼 | 泥沼变可行走地面 |
| 金克木 | 切断藤桥 / 寄生根须 | 封锁敌人路径或打开捷径 |
| 火克金 | 熔断铁门 / 机关锁 | 破解金境机关 |
| 木克土 | 让石墙开裂 / 石化减速 | 开新路或使石化敌人减速 |

### 3.3 与战斗的关系

- 环境五行与敌人破稳共用一套输入与反馈语言，玩家学一次用到底。
- 环境对象不消耗资源即可削减，但速度慢于架势技能；架势技能（如土·镇岳）可快速破环境稳定。
- 序章火墙为第一个验证点，同时作为「水架势」教学的第二应用场景。

## 4. 相生循环连段

### 4.1 概念

- 连续相生切换（木→火→土→金→水→木）触发「循环」状态。
- 循环状态下架势技能消耗减半，持续 6 秒；循环链断裂则清空进度。
- 与既有「切换架势不清空资源」规则兼容。

### 4.2 操作

- 在连段中按 Q（或数字键）切换至相生下一位元素即推进循环进度一格。
- 循环进度以 HUD 上的五行环显示，不额外增加 UI 元素负担。
- 数值（消耗减半、6 秒）为草案，P4 手感调优后回填。

### 4.3 设计意图

- 让「切架势」从「选对的属性」升级为「有节奏的连段」，与东方五行相生环的直觉一致。
- 五境开放后成为高手向操作层，不参与序章教学。

## 5. 腐败成长线

### 5.1 定位

- 独立的中间态系统，不是善恶值：吸收腐败获得力量的同时，世界实时地怕她。
- 与结局计分器解耦：计分器只记录吸收次数（「无相」判定），纹路阶段只影响当下体验。

### 5.2 可见反馈（每吸收 5 次晋升一级，共 3 级）

| 等级 | 外观 | NPC 反应 | 对话 |
|---|---|---|---|
| 0 | 裂纹色浅 | 无 | 正常选项 |
| 1 | 裂纹加深、发尾变灰 | 部分 NPC 压低声音说话 | 出现带腐化文字的「污染选项」 |
| 2 | 裂纹呈脉动状 | 已帮助的 NPC 犹豫、回避 | 污染选项增多，部分净化选项变灰 |
| 3 | 裂纹覆盖半身 | 聚落态度分裂：畏惧与依赖并存 | 终章对话出现专属分支 |

### 5.3 实现约束

- 纹路外观由无央方向帧的腐败纹路覆盖层、颜色遮罩与局部发光实现，裂纹颜色由吸收的元素决定；不依赖可见 3D 人物模型，也不新增 UI 条。
- NPC 反应通过聚落状态机（见《任务结构差异化设计》）的对话表驱动。
- 玩家应始终能「感受」到腐败等级的后果，而不是在结算界面看到分数。

## 6. 场景同伴能力

### 6.1 定位

- 同伴不是可操作战斗单位，而是「能力钥匙 + 叙事视角」。
- 实现为一个同行状态变量 + 能力门控，成本低，但让每境都有「和谁一起走」的选择感。

| 同伴 | 场景能力 | 解锁内容 |
|---|---|---|
| 阿砾 | 读墓契 | 隐藏线索、被删除的名字 |
| 青檀 | 诊断腐败节点 | 标记可净化 / 可吸收的异类 |
| 白刃 | 拆解机关 | 金境机关捷径 |
| 离照 | 点燃与照明 | 火境暗区、余烬提示 |
| 沈汐 | 读取记忆 | 水镜隐藏残响 |

### 6.2 约束

- 主线强制的同行场景只使用对应境的同伴，避免能力门控卡主线。
- 支线与自由探索才使用「选择同行者」的门控。
- 同伴不在战斗场景出现，不参与处决与破稳。

## 7. 本源感应

### 7.1 概念

- 常驻探索技能：按住感应键，世界高亮五行失衡点（腐败节点、可破稳环境对象、隐藏记忆、残响）。
- 不同元素使用不同颜色与音调，色觉差异玩家仍可识别。
- 归墟素衣词条「本源感应范围提高」落地：基础范围常驻，装备后扩大并标记更多类型。

### 7.2 验证点

- 序章归墟出口教学区放置 2 个隐藏残响，只用本源感应可发现。
- 感应不消耗资源、无冷却，定位为探索基础能力而非资源管理。

## 8. 优先级与落地顺序

| 优先级 | 内容 | 落地时机 | 依赖 |
|---|---|---|---|
| P0 | 环境五行（送葬道火墙） | P2 序章灰盒 | 战斗规格的相克削减框架 |
| P0 | 本源感应（基础范围） | P2 序章灰盒 | 无 |
| P1 | 处决 = 取回记忆（首领简化版） | P2 首领战 | 处决系统 |
| P1 | 场景同伴（阿砾读墓契） | 木境 | 聚落状态机 |
| P2 | 相生循环连段 | 第三境之后 | 五架势齐全 |
| P2 | 腐败成长线完整版 | 第二幕之后 | 处决二选一、聚落状态机 |
| P3 | 环境五行全境覆盖 | 各境制作时 | 环境稳定值框架 |

## 9. 验收标准

- [ ] 序章送葬道火墙可用水架势浇灭，且教学主线不依赖它。
- [ ] 首领战处决包含执念闪现与净化/吸收二选一，演出不打断输入节奏。
- [ ] 本源感应可发现序章全部隐藏残响。
- [ ] 相生循环连段在五架势齐全后可连续触发，断裂反馈清晰。
- [ ] 腐败纹路 3 级外观与 NPC 反应全部可验证。
