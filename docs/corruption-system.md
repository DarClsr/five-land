# 腐败系统完整规格

## 1. 定位

腐败吸收是「力量与关系的实时权衡」系统：玩家在处决二选一与剧情选择中吸收腐败，获得力量，同时世界实时地怕她。本规格是 `combat-narrative-fusion.md` 第 5 节框架的完整数值化与触发细则。

## 2. 吸收来源

| 来源 | 频率 | 每次吸收量 |
|---|---|---|
| 首领战处决选「吸收」（执念闪现二选一） | 每首领一次 | +2 |
| 精英战处决选「吸收」 | 每精英一次 | +1 |
| 特定剧情选择（各境腐败节点） | 每境 1–2 处 | +2 |
| 支线选择（如 FL-S02 保留灯芯不计入吸收，仅计共生） | 个别 | +1 |

全流程可吸收总量约 30 点；完全吸收流 ≈ 28–30 点，完全净化流 = 0 点。

## 3. 纹路等级

| 等级 | 累计吸收 | 增益 | 可见反馈 |
|---|---|---|---|
| 0 | 0 | 无 | 裂纹色浅（剧情裂片色） |
| 1 | ≥5 | 伤害 +5%；污染选项出现 | 裂纹加深、发尾变灰 |
| 2 | ≥12 | 架势技能消耗 -10%；污染选项增多 | 裂纹脉动、NPC 回避 |
| 3 | ≥20 | 元素资源上限 +50；终章专属对话 | 裂纹覆盖半身 |

- 纹路等级只增不减（吸收不可逆）；净化行为不降低等级，只阻止继续上升。
- 外观变化直接作用于无央模型材质（combat-narrative-fusion 5.3），不新增 UI 条；HUD 在对话与场景中通过 NPC 反应传达等级（ui-spec 污染选项标记）。

## 4. 污染选项机制

- 触发条件：纹路等级 ≥1，且当前对话存在「可选择吸收/腐化力量」的内容点。
- 表现形式：选项文字以暗红墨色 + 裂纹框标记（ui-spec 第 5 节腐化色），内容为诱惑性表述（「把她的执念吞下去」「让这道裂纹替你记住」）。
- 效果：选择后获得对应增益（资源、伤害、短期强化），计入吸收累计；部分污染选项会改变后续对话与结局计分（循环轴 -1）。
- 规则：污染选项永远是「可选的额外力量」，不阻断主线；净化选项在纹路等级 ≥2 时部分变灰（narrative 约束：吸收到一定程度后，选择本身开始变少）。

## 5. 与聚落状态机的联动

| 纹路等级 | NPC 反应（聚落状态机对话表） |
|---|---|
| 0 | 无特殊反应 |
| 1 | 部分 NPC 压低声音说话，商贩找零时手抖 |
| 2 | 已帮助的 NPC 犹豫、回避目光；槐娘等异类反而更亲近 |
| 3 | 聚落态度分裂：畏惧与依赖并存；阿砾开始用审视的眼神看她 |

## 6. 与结局计分器的关系

- 吸收累计 ≥15 进入「无相」判定线（ending-scorecard）；低于 15 不影响循环/共生轴计算。
- 污染选项的循环轴 -1 独立于吸收累计，两者分别记录。
- 吸收不改变「羁绊」轴（角色任务不受纹路等级影响），但纹路 3 级时终章对话出现专属分支（combat-narrative-fusion 5.2）。

## 6.1 序章吸收的即时反馈（负碑兽）

序章全流程可吸收量仅 2 点（负碑兽处决二选一），低于纹路 1 级阈值（5），玩家若无即时反馈将感受不到吸收的后果。序章专属反馈：

- **吸收（+2）**：处决演出后无央身体裂纹即时加深（黄绿色裂片色扩散至小臂），HUD 提示「裂缝加深了」；返回墟门后阿砾额外台词：「你身上……有墟门的气味了。别让城里人闻见。」后续对话语气染色出现阿砾式警觉（tone 影响，dialogue-system）。
- **净化**：无身体变化；阿砾点头：「干净。和那些尸体不一样。」
- 反馈仅序章生效：第一幕起纹路系统按第 3 节正常推进，序章 +2 计入 `corruption_points` 累计，不影响后续阈值。

## 7. 存档字段

```text
corruption_points          # 吸收累计 0–30
corruption_rank            # 0–3，由 corruption_points 派生
pollution_choice_count     # 污染选项选择次数
```

## 8. 验收标准

- [ ] 全净化流（0 点）与全吸收流（≈30 点）通关均有完整、不矛盾的体验。
- [ ] 纹路 3 级外观与 NPC 反应全部可验证（combat-narrative-fusion 验收项）。
- [ ] 污染选项永不阻断主线，只提供力量与关系权衡。
- [ ] 吸收累计 ≥15 与结局「无相」判定衔接正确。
