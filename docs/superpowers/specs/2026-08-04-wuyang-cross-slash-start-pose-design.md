# 无央双匕交叉斩起手姿势规格

## 目标

基于已验收的无央右前待机帧，生成一张透明高清攻击起手姿势，用作后续 8 帧双匕交叉斩的首帧。本阶段不生成动画，不修改 Godot。

## 姿势合同

- 方向保持右前 3/4 俯视，镜头、角色比例和脚底基线不变。
- 重心压低并落在后腿，前脚朝右前踏出，身体轻微反向蓄力。
- 双匕分开蓄势：一把抬至肩后，另一把横护腰前，为向内交叉斩预留清晰运动路径。
- 保留长白发、双细辫、青瞳、墨青灰白服装和归墟双匕，不改变角色身份。
- 画布为 1:1 透明 PNG，完整保留头发、双匕、双脚及右前方运动空间。
- 不加入元素光效、斩击轨迹、地面、阴影、文字、背景或动态模糊。

## 生成与验收

使用 Meowa `image-edit-run` 的 HD 模式，从已验收待机首帧生成一个候选。检查输出清单、尺寸、RGBA、透明边缘、身份一致性、双匕可读性和脚底锚点，并在游戏内约 100–120 像素角色高度下预览。候选未通过时停止，不自动提交第二个付费任务；起手姿势通过后才规划 8 帧攻击动画。
