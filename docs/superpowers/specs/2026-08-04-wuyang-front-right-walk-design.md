# 无央右前移动动画试产规格

## 目标

基于已验收的无央右前待机形象，试产一个右前方向移动循环。先验证动作、身份一致性和游戏内比例，不批量生成八方向，也不接入 Godot。

## 素材合同

- 表现：HD-2D 高清透明角色，不转换为像素画。
- 方向：镜头右前方，与现有待机方向一致。
- 动作：双匕警戒小跑，重心略前倾，步幅克制，适合即时战斗移动。
- 循环：短循环，首尾连续；头部、躯干、双匕和双脚轮廓清楚。
- 输出：透明 spritesheet，并保留可预览的动画文件。
- 锚点：所有帧脚底基线一致，不允许整体漂移或浮空。

## 验收

检查角色身份、方向、透明通道、帧数、画布尺寸、循环衔接和脚底基线；再以当前 Godot 镜头约 100–120 屏幕像素高度预览。试产通过后，才继续普攻和其余方向。
