# 五行装备与解锁设计

## 设计目标

无央的服装与武器是两个可独立替换的装备槽。服装提供防御、资源或行动类被动，武器改变普通攻击、蓄力攻击和元素技能的动作组。同元素服装与武器同时装备时激活套装共鸣；跨元素混搭则保留各自特性，不触发共鸣。

所有形态固定保留黑色及腰高马尾、深色瞳孔、脸型与约七头身成熟比例。服装、束发饰件和武器可以独立替换并承担五行辨识，但不得改变脸型、发际线、体型与基础剪影，避免把主角画成六个不同角色。

## 解锁节奏

| 阶段 | 解锁内容 | 用途 | 任务节点 |
|---|---|---|---|
| 序章初始 | 归墟素衣、归墟双匕 | 教学移动、闪避取消、贴身连击与本源感应 | 初始持有 |
| 木境主线 | 裁枝藤镰、青蘅生衣 | 引入标记、牵引与续航 | 裁枝藤镰 `MU-P04`（由走私刃具改造，见 `woodland-quests.md`）；青蘅生衣 `MU-P06` |
| 金境主线 | 断契双刃、白铸影衣 | 引入背袭、精准闪避与破稳 | 断契双刃 `JI-P03`；白铸影衣 `JI-P06` |
| 火境主线 | 燎原长枪、赤烬誓衣 | 引入中距离压制、灼烧与突进爆发 | 待火境任务表定稿后回填 |
| 水境主线 | 回潮月伞、玄溟潮衣 | 引入控制、位移与节奏型战斗 | 待水境任务表定稿后回填 |
| 土境深层 | 镇岳石臂、镇岳垣衣 | 防御反击、减伤与破稳（压轴流派） | 待土境深层任务表定稿后回填 |

服装和武器通过同一章节中的不同任务节点分别获得，使玩家在完成整套前先体验混搭；两节点之间玩家处于「武器先到、服装后到」的混搭窗口。木境裁枝藤镰由 `MU-P03` 发现的走私刃具改造而来，与金境交织点 A 形成装备闭环。

## 初始武器：归墟双匕

归墟双匕是一对素黑、没有五行铭文的短刃，确立无央轻装刺客的基础战斗身份。双匕不附带元素状态，攻击距离短、攻速快，可在连击中使用闪避取消，用来教授贴身走位、快速轻击、蓄力交叉斩和处决。获得五行武器后仍可装备，适合高机动、无元素共鸣的构筑。

## 火行：燎原长枪

燎原长枪采用深色枪杆、叶形枪头与短红缨，火焰只集中在枪尖，不让整根武器持续燃烧。基础枪术由连续突刺、横扫和踏步前冲组成；命中为敌人叠加灼烧，枪术终结技集中引爆。它比双匕拥有更安全的攻击距离，但转身与收招更慢，需要玩家提前控制站位。

## 金行：双刀刺客

### 外观

- 服装采用银灰、墨黑与少量冷青，窄袖、短下摆、贴身内衫和轻量锐角护片，保证高速动作时四肢清楚可读。
- 保留主角黑色长高马尾，以短金属发冠和束带收紧上半身轮廓；不使用厚重披风或整片板甲。
- 志怪细节使用刻有断裂契文的银片、封口红线与小型镇魂铃，避免变成普通忍者或西式盗贼。

### 武器

“断契双刃”为一长一短的成对兵器。长刃负责突进、扫击和正面削甲，短刃负责贴身反握、背袭与收割。两把刀的纹样拼合时形成一张被斩断的墓契。

### 战斗特性

- 普攻：快速五段连击，第三段可穿到轻型敌人身后。
- 蓄力：交叉斩击，消耗金行资源并削减稳定值。
- 精准闪避：短时间进入“听隙”，背后攻击获得额外伤害与破稳。
- 限制：正面硬拼能力弱，范围控制小，失去节奏后需要重新创造背袭位置。

## 视觉参考与生产约束

- 当前六形态总览参考：`docs/art/references/wuyang-five-elements-costume-lineup-v3.png`。
- v3 已将初始武器改为「归墟双匕」、火行武器改为「燎原长枪」，并保留金行一长一短的「断契双刃」；v1、v2 只作为设计过程记录，不用于生产。
- 每套造型单独生成 1024×1024 透明高清角色母版，禁止把总览图整体缩小或切图当作最终素材。
- 静态形态验收后再制作待机、移动、闪避、普攻、受击与专属技能动画；所有动作使用统一脚底锚点。

## 数据落地建议

后续在 Godot 中分别创建 `EquipmentDefinition`、`WeaponDefinition` 与 `SetResonanceDefinition` 资源。装备只保存数值、标签、动作组和图标引用；实际的伤害、状态与冷却由现有能力和五行规则系统执行，避免把玩法逻辑写进 UI 或场景节点。
