# Five Land

一款 HD-2D 东方黑暗奇幻游戏。

玩家将扮演从深渊归来的异类女孩。她是五行本源碎片的容器，将在探索五行天地、追查腐败之谜的过程中，决定世界走向修复还是毁灭。
